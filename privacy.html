개인정보처리방침

적용일: 2026-11-17. ku-lms-monitor는 계정 소유자가 운영하는 개인용 학업 알림 도구입니다.

Google 데이터 사용

gmail.send 범위만 요청합니다. OAuth 인증정보를 사용해 지정된 수신 주소로 LMS 변경 알림을 전송하며, 받은편지함·연락처·기존 메일 본문을 읽거나 삭제하지 않습니다.

저장과 전달

OAuth 인증정보는 암호화된 GitHub Actions Secrets를 통해 Google Secret Manager에 전달하며, 실행 계정의 접근을 제한합니다. 발송 여부와 메시지 ID는 중복 방지를 위해 비공개 Cloud Storage에 저장합니다. 알림 내용은 Google Gmail과 소유자가 지정한 수신 계정에 전달됩니다. Gmail을 통해 받은 데이터나 OAuth 인증정보를 AI 모델에 전달하지 않습니다.

제한된 이용과 보관

Google API로 받은 정보의 사용 및 다른 앱으로의 전달은 Google API Services User Data Policy의 Limited Use 요구사항을 따릅니다. 광고, 판매, 신용평가 또는 일반 목적 AI 모델 학습에 사용하지 않습니다. 소유자가 운영하는 알림과 장애 확인에 필요한 범위에서만 보관합니다.

권한 철회와 삭제

소유자는 Google 계정의 연결된 앱 설정에서 권한을 철회하고, 본인이 관리하는 Secret Manager·GitHub Secrets·비공개 저장소에서 인증정보와 기록을 삭제할 수 있습니다. 이 공개 안내 사이트의 저장소 이슈로 정책 문의를 남길 수 있으나 비밀값이나 개인 학업 자료를 게시해서는 안 됩니다.
